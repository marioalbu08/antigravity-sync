# Contributing to Antigravity Sync

Thanks for your interest in contributing! 🚀

## How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally.
3. Create a new **branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/my-awesome-feature
   ```
4. Make your changes and **commit** them with clear messages.
5. **Push** your branch and open a **Pull Request**.

## Reporting Bugs

If you find a bug, please open an [Issue](https://github.com/marioalbu08/antigravity-sync/issues) with:
- Your OS (Windows / macOS / Linux)
- Python version (`python --version`)
- Steps to reproduce the bug
- The full error message / traceback

## Code Style

- Use clear, descriptive variable and function names.
- Add docstrings to all public functions.
- Keep functions focused and under 50 lines where possible.

## Feature Requests

Have an idea? Open an Issue with the `enhancement` label and describe:
- What problem it solves
- How you imagine it working

Thanks for making Antigravity Sync better! ❤️
